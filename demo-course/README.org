#+TITLE: Demo Course: Introduction to Data Science (DS 101)

* Overview

This directory contains a complete, self-contained demo course that showcases every content type =org-canvas= pushes and every property you can set on one.  It is designed as a realistic 15-week university course to illustrate how all content types, properties, and linking patterns work together.

*This is a reference example, not a live course.*  The =sections.org= file contains representative CANVAS_ID values for demonstrating override links.  PDF files in =content/= are placeholders.

** Other Features

- *Per-section date overrides* -- See the =#+NAME: overrides= table in the Midterm Exam assignment
- *Multi-level rubric ratings* -- See the Project Rubric (4 rating levels per criterion)
- *File folder hierarchy* -- Syllabus, Lectures, Labs, Resources folders in =files.org=
- *Usage rights and licensing* -- Multiple justification types in =files.org=
- *Cross-file module linking* -- =modules.org= links to pages, assignments, quizzes, discussions, announcements, and files
- *External URL module items* -- Course Textbook Website in Week 02
- *SubHeader module items* -- "--- Setup ---" divider in Week 01
- *Completion requirements* -- must_view, must_submit, must_contribute, min_score
- *Practice quiz* -- Ungraded self-assessment with show/hide correct answer dates
- *Graded discussion* -- Midterm Study Group with points and assignment group link
- *Checkpointed discussion* -- the Debate grades the first post and the replies separately, each with its own due date
- *Kept out of modules on purpose* -- =NO_MODULE: true= on Student Resources, the practice quiz, Midterm Study Group, the extra-credit assignment and =lab02-data.csv=; every other published item is linked from =modules.org=, so =org-canvas-validate= has no "in no module" notes
- *Scheduled publishing* -- the Midterm Review Guide page (=PUBLISH_AT=), the Week 03 module and the Quiz 02 module item
- *Post policy and scheduled posting* -- Midterm Exam hides its grades and posts them on a schedule, comments first
- *Rubric as the grade* -- Lab 02 (=RUBRIC_USE_FOR_GRADING=); the Final Project hides the rubric's score total
- *LTI assignment* -- Homework 02 launches Gradescope, named by URL and by tool id
- *Document processor intent* -- Homework 01 asks for Turnitin (=WANT_DOCUMENT_PROCESSOR=) beside the =DOCUMENT_PROCESSOR= a pull recorded
- *Anonymous survey* -- Mid-Semester Feedback Survey in =quizzes.org=
- *Section meeting times* -- =MEETS= in =sections.org=, read when a grading file is scored by section window

** What It Leaves Out

Some files are written only by a pull and hold students' names, posts or grades: =people.org=, =groups.org=, =discussion-replies.org=, =gradebook.org= and =quiz-results.org= (with =rubric-results.org= beside it).  The manual says to keep them out of a course repository, so the demo ships none of them.  The grading files under the submissions directory are left out for the same reason.

* How to Use

1. Copy this directory and configure =org-canvas-credentials.el= with your Canvas URL and API token
2. Set =org-canvas-directory= to point to your copy
3. Run =M-x org-canvas-validate= to check for issues.  The demo validates with no errors; the three "sync it first" warnings name headings that have never been pushed and go away after the first sync
4. Run =M-x org-canvas-sync= to push everything to Canvas
