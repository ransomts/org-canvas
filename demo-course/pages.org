Follow these steps to set up your development environment for DS 101.

*Step 1: Install Python 3.10+*

Download from [[https://www.python.org/downloads/][python.org]] or use your system package manager.  Verify with:

#+begin_example
python --version
#+end_example

*Step 2: Install Jupyter*

#+begin_example
pip install jupyterlab
#+end_example

*Step 3: Install Required Libraries*

#+begin_example
pip install pandas numpy matplotlib seaborn scikit-learn
#+end_example

*Step 4: Verify Installation*

Launch Jupyter Lab and run:

#+begin_src python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
print("All set!")
#+end_src

If you see "All set!" with no errors, your environment is ready.
