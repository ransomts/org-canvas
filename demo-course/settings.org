*Welcome to DS 101 -- Introduction to Data Science!*

This course provides a hands-on introduction to the tools and techniques of data science.  Students will learn to collect, clean, analyze, and visualize data using Python and its ecosystem.

*Learning Objectives:*
1. Write Python programs to manipulate and analyze data
2. Apply statistical methods to draw conclusions from data
3. Create effective data visualizations
4. Communicate findings through written reports and presentations
