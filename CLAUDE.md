# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository. It is the short guide: the hard rules and conventions are imported below and always loaded; the rest is one link away. The reasoning behind every rule lives in `documentation/architecture/` (see "Where the Narratives Live" in the architecture guide); when a rule cites a heading, read it before touching that code.

## Project Overview

org-canvas is an Emacs Lisp package that synchronizes course content from Org Mode files to Canvas LMS via its REST API. Org files are the "source of truth": instructors design courses in Org Mode and push changes to Canvas.

Content types, one module each: assignments (including LTI/external-tool assignments such as Gradescope), classic quizzes, new quizzes, pages, modules, rubrics, outcomes, discussions, announcements, files, assignment groups, group categories, calendar events, sections (pull-only), grading periods (pull-only), grading schemes, per-section date overrides, per-student quiz accommodations, and course settings. Submission grading (`org-canvas-submissions.el`: view, comment, download attachments, push grades, rubric assessments and late statuses, keep SpeedGrader's comment bank) is a separate feature, not a content type.

## Every Change

```bash
eldev test           # All tests; the last line prints the spec count
eldev lint           # Must pass before every push
eldev complexity     # Target: 0 functions above 15
eldev clean all      # Mandatory after editing a macro
```

- **Lint under Emacs 30.1, not a newer local Emacs.** Its checkdoc rejects a third-person verb such as "holds" anywhere in a docstring's first line, and any docstring line over 80 columns. The pre-push hook lints under the pinned Emacs 30; setup.md has the details.
- **Changelog: one fragment per PR, never CHANGELOG.org.** Add `changelog.d/<issue>.org` (a `* Added`/`* Changed`/`* Fixed` heading, then `- #<issue> ...` items; `changelog.d/README.org`), checked by `scripts/changelog-collect.py --check`.
- **codecov/patch gates every PR:** each `lisp/` line a PR adds must run under a test (`python3 scripts/patch-coverage.py`, testing guide).
