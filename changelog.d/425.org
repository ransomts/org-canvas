* Added
- #425 =org-canvas-push-submission-comment-edits= (=C= in a grading file and in the dispatch menu's Submissions group) sends only the sent comments rewritten or marked =DELETE= in a grading file: no score, rubric row, late status, drafted comment or Comment Bank item, and nothing is posted, so the wording of feedback already sent can be fixed while the grades stay held. The changes are checked, listed and confirmed as the full push does it, a dry run sends nothing, a read-only course refuses before anything is sent, and the new baselines are written through the package's own save path, so a batch run never stops at a "changed since visited" question. From a script it takes the grading file by assignment id or name with no prompt and returns =:edited=, =:deleted=, =:refused=, =:failed= and =:dry-run=; =scripts/org-canvas push-comments ASSIGNMENT...= runs it from the shell and exits 1 when a change was not sent. =org-canvas-push-submission-grades= reports =:refused=, =:failed= and =:dry-run= for sent comments too
