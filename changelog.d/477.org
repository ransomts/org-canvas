* Fixed
- #477 A full sync leaves a working link in the syllabus to a file new to =files.org=.  The syllabus is pushed with the course settings, before files are uploaded, so such a link first went as plain text with a warning and was fixed only by a second sync.  =org-canvas-sync= now holds back that warning and, once the files tier has given the file a =CANVAS_ID=, pushes the syllabus again in one request, only when such a link was waiting.  A link still unresolved after the files tier, or under a dry run, is warned about as before; =org-canvas-sync-settings= run on its own is unchanged
