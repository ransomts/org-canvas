* Added
- #670 =org-canvas-diff-at-point= checks the heading at point for drift without running the whole report, and =org-canvas-diff-headings= (=scripts/org-canvas diff FEATURE:TITLE...=, with =--json=) checks headings named by title or Canvas id. Each heading's object is read on its own, by the id its drawer holds now, and gets the row the full report would give it: CHANGED, MISSING, a NOTE, or PENDING when it has no id. The return value and exit status count the divergences plus each heading that could not be checked, so a script can refuse to push on non-zero. Nothing is written, and =g= in the report checks the same headings again.
