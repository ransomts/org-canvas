- #435 A folder-path read that fails with anything but a 404 — a 401 above all — no longer masquerades as a missing folder and fires a create; the error is named in one line and re-signaled, so nothing is created on Canvas's word alone.  A module-item liveness read that fails and a grading-file refresh whose assignment read fails each say so with one warning instead of answering silently.  A course that renames its =org-canvas-*-file= defcustoms keeps its module items typed and their links resolving: the type map and the item-link resolvers read the course's own file vars at call time instead of the default filenames spelled as literals, and a module item's link carries the path relative to the modules file, so it stays clickable wherever the files live.  A failed attachment download re-signals with the access token masked, and the token-as-query-parameter stays, documented: Canvas's download route redirects to a presigned URL whose own signature lives in the query string, and a request carrying both that signature and an Authorization header is rejected
