  =<time>-<type>-all.json= under =org-canvas-diff-delete-snapshot-directory=

  confirmations are unchanged, and a run refused by the write-scope
  allowlist, a read-only course, or an empty listing writes no
  snapshot: no file claims a delete that did not happen.
