* Commands

** Sync

| Key (in dispatch) | Command                 | Description                 |
|-------------------+-------------------------+-----------------------------|
| =s s=               | =org-canvas-sync=         | Sync all (with conflicts)   |
| =s d=               | =org-canvas-sync-dry-run= | Preview sync (reads, never writes) |
| =s f=               | =org-canvas-force-push=   | Sync all, skip conflicts    |
| =s @=               | /sync-at-point submenu/   | Sync single heading         |

** Pull

| Key (in dispatch) | Command             | Description                 |
|-------------------+---------------------+-----------------------------|
| =p a=               | =org-canvas-pull-all= | Import entire Canvas course |
| =p P=               | /pull-single submenu/ | Pull one content type       |

** Delete

| Key (in dispatch) | Command                    | Description               |
|-------------------+----------------------------+---------------------------|
| =D d=               | =org-canvas-delete-all=      | Delete ALL course content |
| =D c=               | =org-canvas-cleanup-orphans= | Find and remove orphans   |
| =D X=               | /delete-at-point submenu/    | Delete single heading     |

** Tools

| Key (in dispatch) | Command                     | Description               |
|-------------------+-----------------------------+---------------------------|
| =t i=               | =org-canvas-init=             | Setup wizard              |
| =t t=               | =org-canvas-test-connection=  | Test API connection       |
| =t v=               | =org-canvas-validate=         | Validate offline (no API) |
| =t s=               | =org-canvas-status=           | Sync status overview      |
| =g v=               | =org-canvas-submissions-view= | View/grade submissions    |

Open the dispatch menu: =M-x org-canvas-dispatch=

** quizzes.org

| Property                     | Type   | Values / Notes                                   |
|------------------------------+--------+--------------------------------------------------|
| =QUIZ_TYPE=                    | string | assignment, practice_quiz, graded_survey, survey |
| =TIME_LIMIT=                   | number | Minutes                                          |
| =SHUFFLE_ANSWERS=              | bool   |                                                  |
| =ALLOWED_ATTEMPTS=             | number | -1 = unlimited                                   |
| =DUE_AT= / =UNLOCK_AT= / =LOCK_AT= | ts     |                                                  |
| =ACCESS_CODE=                  | string | Password for quiz access                         |
| =SCORING_POLICY=               | string | keep_highest, keep_latest                        |
| =SHOW_CORRECT_ANSWERS=         | bool   |                                                  |
| =ONE_QUESTION_AT_A_TIME=       | bool   |                                                  |
| =CANT_GO_BACK=                 | bool   | Requires =ONE_QUESTION_AT_A_TIME=                  |
| =IP_FILTER=                    | string | IP range                                         |
| =GROUP=                        | link   | Assignment group link                            |

Question properties: =TYPE= + =POINTS=.  Types: multiple_choice, true_false, short_answer, essay, matching, numerical, multiple_answers, fill_in_multiple_blanks, multiple_dropdowns, file_upload, text_only.

Answers: =[X]= = correct, =[ ]= = wrong.  Matching: =Left = Right=.  Numerical: =[X] 42= or =[X] [1, 10]=.

** modules.org

** rubrics.org

Properties: =FREE_FORM_CRITERION_COMMENTS=, =HIDE_SCORE_TOTAL= (both boolean).

Criteria table: | Criterion | Points | Long Description | Outcome link |

Multi-level ratings: rows prefixed with => =:

#+begin_example
| Code Quality |   10 | ...           |
| > Excellent  |   10 | Outstanding   |
| > Good       |    7 | Solid         |
| > Poor       |    0 | Unacceptable  |
#+end_example

* Type Legend

| Abbreviation | Meaning                                    |
|--------------+--------------------------------------------|
| ts           | Org timestamp: =<2026-09-15 Mon 23:59>=     |
| bool         | =true= or =false=                              |
| enum         | One of the listed values                   |
| link         | =[[file:other.org::*Heading][Heading]]=      |
| auto         | Set automatically by org-canvas after sync |
| number       | Integer                                    |
| string       | Free text                                  |

* Sync Order

#+begin_example
Tier 0:   settings, sections (pull)
Tier 0.5: assignment-groups (phase 1, no drop rules)
Tier 1:   group-categories, outcomes, rubrics, pages,
          files, discussions, announcements, calendar
Tier 1.5: assignments, quizzes, new-quizzes
Tier 1.75: overrides
Tier 2:   assignment-groups (phase 2, with drop rules)
Tier 3:   modules
#+end_example

* Conflict Resolution Keys

| Key | Action                             |
|-----+------------------------------------|
| =p=   | Push (overwrite Canvas)            |
| =l=   | Pull (accept Canvas, update local) |
| =s=   | Skip (leave both untouched)        |
| =P=   | Push ALL remaining                 |
| =L=   | Pull ALL remaining                 |
| =S=   | Skip ALL remaining                 |

* Submissions Viewer Keys

| Key | Action                     |
|-----+----------------------------|
| =v=   | Toggle summary/detail view |
| =c=   | Post comment               |
| =d=   | Download attachments       |
| =S=   | Push changed grades        |
| =g=   | Refresh from Canvas        |
| =q=   | Quit                       |
