* Commands

Open the dispatch menu: =M-x org-canvas-dispatch=.  Every key is a single keystroke in that menu.

** Sync

| Key | Command                            | Description                        |
|-----+------------------------------------+------------------------------------|
| =s=   | =org-canvas-sync=                    | Sync all (with conflicts)          |
| =d=   | =org-canvas-sync-dry-run=            | Preview sync (reads, never writes) |
| =f=   | =org-canvas-force-push=              | Sync all, skip conflicts           |
| =@=   | /sync-at-point submenu/              | Sync single heading                |
| =b= / =B= | =org-canvas-browse-at-point= / =-browse-edit-at-point= | Open the heading's Canvas page / edit page |

** Pull

| Key | Command                     | Description                                   |
|-----+-----------------------------+-----------------------------------------------|
| =p=   | =org-canvas-pull-all=         | Import entire Canvas course                   |
| =P=   | /pull-single submenu/         | Pull one content type                         |
| =u=   | =org-canvas-pull-at-point=    | Replace the heading at point with Canvas's version |
| =A=   | =org-canvas-adopt-at-point=   | Stamp the heading with the Canvas item of its title |

From Lisp: =(org-canvas-pull-page TITLE)= and the same for each feature (=org-canvas-pull-assignment=, ...), or =org-canvas-pull-headings= for a list; no prompt, file saved.

** Delete

| Key | Command                      | Description               |
|-----+------------------------------+---------------------------|
| =D=   | =org-canvas-delete-all=        | Delete ALL course content |
| =O=   | =org-canvas-cleanup-orphans=   | Find and remove orphans   |
| =X=   | /delete-at-point submenu/      | Delete single heading     |

** Submissions

| Key | Command                                        | Description                          |
|-----+------------------------------------------------+--------------------------------------|
| =g=   | =org-canvas-pull-submissions=                    | Pull an assignment into a grading file |
| =Q=   | =org-canvas-submissions-status=                  | Grading queue                        |
| =o=   | =org-canvas-open-submissions=                    | Open a saved grading file            |
| =q=   | =org-canvas-pull-quiz-submissions=               | A classic quiz's attempts (read-only) |
| =w=   | =org-canvas-pull-peer-reviews=                   | An assignment's peer reviews (read-only) |
| =a=   | =org-canvas-submissions-apply-completion-rule=   | Fill empty scores by completion      |
| =G=   | =org-canvas-submissions-push-grades=             | Push grades                          |
| =T=   | =org-canvas-submissions-post-grades=             | Post grades to students              |
| =Y=   | =org-canvas-submissions-verify=                  | Read a push back from Canvas (read-only) |

* Type Legend

| Abbreviation | Meaning                                    |
|--------------+--------------------------------------------|
| ts           | Org timestamp: =<2026-09-15 Mon 23:59>=     |
| bool         | =true= or =false=                              |
| enum         | One of the listed values                   |

* Sync Order

#+begin_example
Tier -1:   grading-schemes, settings
Tier 0:    outcomes, rubrics, assignment-groups (phase 1, no drop rules),
           group-categories, sections (pull), grading-periods (pull),
           files, pages, discussions, announcements, calendar
Tier 1:    quizzes, new-quizzes, assignments
Tier 1.5:  assignment-groups (phase 2, with drop rules)
Tier 1.75: overrides, quiz accommodations
Tier 2:    modules
#+end_example

* Conflict Resolution Keys

| Key | Action                             |
|-----+------------------------------------|
| =p=   | Push (overwrite Canvas)            |
| =l=   | Pull (accept Canvas, update local) |
| =s=   | Skip (leave both untouched)        |
| =P=   | Push ALL remaining                 |
| =L=   | Pull ALL remaining                 |
| =S=   | Skip ALL remaining                 |

* Grading File Keys

| Key | Action                                                     |
|-----+------------------------------------------------------------|
| =v=   | Toggle summary table / grading file                        |
| =c=   | Post a comment on the student at point                     |
| =d=   | Download the attachments at point                          |
| =D=   | Download every student's attachments                       |
| =S=   | Push changed scores, rubric rows, late statuses, drafted comments and new Comment Bank items |
| =P=   | Post grades to students (manual post policy)               |
| =g=   | Refresh from Canvas (typed work comes back)                |
| =B=   | Read SpeedGrader's comment library into =* Comment Bank=    |
| =x=   | Delete the Comment Bank item at point on Canvas (asks)     |

Per student: =SCORE= (or =EX=), =LATE_STATUS= (late, missing, extended, none), a =Rubric= table, a =Comment to post= draft.  Written by pull: =CANVAS_SCORE=, =CANVAS_LATE_STATUS=, =DAYS_LATE=, =ATTEMPT=, =GRADED_ATTEMPT=, =SIMILARITY=, =AI_WRITING=, =CONFLICT=.

* Drift Report Keys

In =*canvas-diff*= (=M-x org-canvas-diff=):

| Key       | Action                                                          |
|-----------+-----------------------------------------------------------------|
| =RET=       | Visit the heading, or open the Canvas object of an EXTRA/MOVED row |
| =b= / =B=   | Open the Canvas page / edit page                                |
| =a=         | Acknowledge an EXTRA/UNCLAIMED/MOVED row; adopt the stamp of a CHANGED row with nothing to compare |
| =k=         | Delete the remote object (asks; JSON snapshot saved first)      |
| =p=         | Pull the Canvas version (CHANGED; EXTRA quizzes and New Quizzes) |
| =s=         | Stamp a MOVED row's item id on its paired heading               |
| =S=         | Stamp every MOVED row paired by content                         |
| =g=         | Run the report again                                            |
| =TAB= / =S-TAB= | Next / previous row                                         |

Batch deletion of EXTRA rows: =org-canvas-diff-delete-rows=.
