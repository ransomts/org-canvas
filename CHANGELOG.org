* Unreleased

** Added

- #184 =DOCUMENT_PROCESSOR= on assignments: the Turnitin document processor attached in the web UI is written by pull, shown by the drift report whether or not the heading carries it, never sent by a push, and flagged by validate when typed ahead of the first sync; Canvas attaches one only in a browser, so org-canvas observes and protects it rather than setting it
- #179 (follow-up) Every remaining create path adopts a twin before it POSTs: classic quiz questions and New Quiz items match an unclaimed item of their name in the parent's list, New Quizzes ask the same adopt/skip/create question as the generic guard, outcomes and outcome groups search their parent before creating, the generic 404 recovery updates the item that still carries the title instead of POSTing a second, and classic quizzes, discussions, announcements and assignment groups gain a =:find-fn= so a push at point is guarded outside a sync's snapshot
- #164 Duplicate-title detection for pages, assignments, quizzes, new quizzes, rubrics, discussions, announcements and modules: the offline validator groups titles once =(OLD)=, semester stamps and Canvas's =(n)= suffixes are stripped, raising a twin that still carries a =DUE_AT= to an error; =org-canvas-pull-all= names the types whose titles collapse
- #163 =org-canvas-read-only=: mark an adopted course read-only in its credentials file and every write is refused at the transport, the menu's push half greys out, and =org-canvas-init= asks whether the course is yours
- #127 Submissions: completion rule, =DAYS_LATE=, notes that survive pulls, and =EX= for excused grades
- #126 Submissions: draft comments in the grading file and post them with =S=
- #119 =RUBRIC_USE_FOR_GRADING= and =RUBRIC_HIDE_SCORE_TOTAL= on assignments
- #117 Submissions: link the assignment's rubric and list its criteria
- #116 Submissions: link the assignment, SpeedGrader, and local attachments
- #115 Submissions: grading files that survive the session
- #110 Drift report rows have verbs: visit, acknowledge, delete, and pull
- #109 Drift report recognizes media that course content embeds instead of listing it as extra
- #108 Module items moved between modules are reconciled instead of duplicated
- #107 =org-canvas-adopt-at-point= adopts the Canvas item that shares a heading's title
- #100 Known-extras and excluded-features valves let a synced course read zero divergences
- #90 Calendar events register as a feature: drift checks, duplicate guard, and pull-at-point
- #88 External-tool (LTI) assignments such as Gradescope; skipped items are reported by name; pull includes the front page

** Changed

- #155 A 403 your Canvas role cannot do anything about is reported as a permission skip, named in the closing line and recorded in the pull summary, instead of counted as a failure; the summary prints to stdout under =--batch=
- #156 Pagination progress names the resource and speaks only when a fetch really is paging; the first page is logged, not announced
- #141 Sync run state (batch conflict answers, the module's pull function, the moved/pending/changed id lists) lives in a per-run context instead of dynamically bound globals, so nothing one run decides reaches the next
- #142 Every pause a sync takes goes through =org-canvas--wait=, which counts down in the echo area and keeps the display alive; the settings pull says so when the late policy or navigation tabs cannot be read; =org-canvas.el= split into status, publish, adopt, and orphans command files
- #140 Emacs 29.1 is the minimum (was 28.1); obsolete =when-let= replaced; a clean compile is warning-free; this changelog

** Fixed

- #178 The bearer token is no longer an argument on the request path, so a backtrace of an api-error escaping a batch script cannot print it: the headers are resolved inside the transport function, request logging never reads the token, and plz's own frames are unwound before the error reaches a debugger
- #158 A nested =files.org= can be re-pulled: files are matched by Canvas id wherever they sit, a file whose folder changed is moved rather than duplicated, and hand-written content survives; downloads skip a local copy that is already the right size
- #153 Navigation tabs are pulled again: Canvas sends a JSON array, which =json-read= decodes as a vector, and the formatter walked it with =dolist=
- #157 An optional require is optional again: a feature that is on =load-path= but raises while loading no longer aborts loading org-canvas, and says what was lost
- #152 Unwrap plz's error datum: it signals =plz-http-error= with a list, not a bare struct, so session cookies escaped masking, Canvas's own error text was replaced by a printed struct, and 429 and 5xx were never retried on the primary request path
- #154 Redact on the way to the user, not only to the log: error text sent through =message= or stored in the pull summary reached stdout unmasked
